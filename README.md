# Fortune Cookie Generator

A simple Fortune Cookie web app built using Python and Streamlit.

## Features
- Enter your name
- Get a random fortune
- Cute and simple UI
- Deployed using Streamlit Community Cloud

## Technologies Used
- Python
- Streamlit
- GitHub
